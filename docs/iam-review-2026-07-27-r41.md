### 3.2 JAR ParseUnverified — P2

**文件**: `services/oauth/internal/service/jar_mtls.go:106`

```go
parser := jwt.NewParser(jwt.WithoutClaimsValidation())
_, _, err := parser.ParseUnverified(requestJWT, claims)
```

JAR (RFC 9101) 要求 request JWT 签名验证。当前使用 `ParseUnverified` 仅提取 claims，不验证签名。iss==client_id 验证存在但不充分。

| P2-60 | P2 | JAR ValidateJARRequest 使用 ParseUnverified — 不验证 request JWT 签名 |
