## 3. 安全审查

### 3.1 Consent bypass — ✅ 安全

`consent=true` 是 URL query param，但需要认证 user_id。Extended scope 检查 + consent_given 验证正确。与 Keycloak/Auth0 设计一致。

### 3.2 MFA challenge 重放 — ✅ 安全

`mfa_service.go:121`: `device.LastUsedCode == code` 拒绝同一 TOTP code 重用 (RFC 6238 §5.2)。Skew=1 容忍 ±30s 时钟漂移。

### 3.3 Token revocation — ⚠️ 内存黑名单

`token_revocation.go:57`: 黑名单存储在内存 `map[string]*revocationEntry`。重启后丢失 — 已撤销的 token 可能在重启后再次有效（直到自然过期）。

| P2-61 | P2 | Token revocation 黑名单是内存存储 — 重启后丢失，已撤销 token 可重新使用 |

### 3.4 Console XSS — ✅ 安全

`layout.tsx:47`: `dangerouslySetInnerHTML` 仅包含内联 dark mode 检测脚本，无用户输入注入点。

### 3.5 P1-13 修复确认 ✅
