## 3. 安全审查

### 3.1 认证流 — ✅ 安全（含一个 P1 问题）

- JWT RS256 + alg whitelist ✅
- iss 验证强制 ✅
- aud 验证（5 个外部端点）✅
- client_secret timing-safe 比较 ✅
- authorization code client binding ✅ (`code.ClientID != client.ID`)
- redirect_uri 验证 ✅ (early validation + token endpoint mismatch check)
- PKCE S256 强制 ✅

**P1-1: refresh token 未验证 client_id 绑定**
`RefreshToken()` 函数 (oauth_service.go:1605) 查找 refresh token 记录后，未检查 `record.ClientID == req.ClientID`。攻击者可以用 client B 的凭据使用 client A 的 refresh token 获取新 access token。
```
// 当前代码（缺少）:
record, err := s.tokenRepo.GetRefreshToken(ctx, req.TenantID, tokenHash)
// ... 后续直接使用 record，未验证 record.ClientID == client.ID
```
修复建议：在 step 4 和 step 5 之间添加：
```go
if record.ClientID != client.ID {
    return nil, errors.Unauthenticated("refresh token was issued to a different client")
}
```

- access_token: JWT with iss/sub/aud/exp/iat/jti/tenant_id
