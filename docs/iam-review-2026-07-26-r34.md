## 3. 安全审查（新维度）

### 3.1 密码策略 — ✅ 安全

- `Register()` 调用 `passwordService.Validate(password)` ✅
- 密码策略支持 MinLength, RequireUpper/Lower/Digit/Special, Blacklist, HistoryCount, MaxAgeDays ✅
- Argon2id 哈希 ✅
- breach detection ✅

### 3.2 账户锁定 — ✅ 安全

- `AccountLockoutService` 通过 Redis 计数器实现 ✅
- `MaxAttempts` + `LockDuration` 可配置 ✅
- `IsLocked()` 检查 + `ResetFailedAttempts()` ✅
- IP 级别限制 + anomaly detection ✅

### 3.3 CSRF 防护 — ✅ 安全（有细微差距）

- Double-submit cookie 模式 ✅
- GET/HEAD/OPTIONS 设置 csrf_token cookie ✅
- POST/PUT/DELETE 验证 X-CSRF-Token header 匹配 cookie ✅
- 跨客户端 CSRF 防护（state 隔离）✅

| ID | 严重性 | 描述 |
|----|--------|------|
| P2-27 | P2 | CSRF cookie 使用 `SameSite: LaxMode` 而非 `StrictMode`（安全测试期望 StrictMode）。LaxMode 允许跨站 GET 导航携带 cookie，为 OAuth 重定向兼容性可接受但略弱 |

### 3.4 HTTP 安全头 — ✅ 安全

- X-Content-Type-Options: nosniff ✅
- X-Frame-Options: DENY ✅
- X-XSS-Protection: 1; mode=block ✅
- Strict-Transport-Security: max-age=31536000; includeSubDomains ✅
- Content-Security-Policy ✅
- Referrer-Policy: strict-origin-when-cross-origin ✅
- 可配置 HSTS（HSTSMaxAge=0 时禁用）✅

### 3.5 Cookie 安全 — ✅ 安全

- Secure: true ✅
- HttpOnly: true ✅
- SameSite: LaxMode ✅（为 OAuth 重定向兼容性）

### 3.6 租户头注入防护 — ✅ 安全

- Gateway Director 始终覆盖 X-User-ID（有 JWT 时设验证值，无 JWT 时删除）✅
- X-Tenant-ID 始终从 JWT claim 设置 ✅
- 客户端无法伪造 X-User-ID / X-Tenant-ID ✅

### 3.7 Session Fixation — ⚠️ 差距

| ID | 严重性 | 描述 |
|----|--------|------|
| P2-28 | P2 | 登录时未见显式 session ID 重新生成。Register/Login 创建新 session 但未检查是否已有 pre-login session 需要失效 |

### 3.8 跨服务认证 — ✅ 安全

- `GGID_INTERNAL_SECRET` 用于 SCIM token hashing、SDJWT、secret broker、wasm 插件签名 ✅
- 未设置时拒绝启动（secret broker、SCIM token、SDJWT handler 均有检查）✅

### 3.9 Webhook 安全 — ✅ 安全

- SSRF 防护：`validateWebhookURL` 拒绝 private IP 和 localhost ✅
- HMAC-SHA256 签名：`X-GGID-Signature` header ✅
- 指数退避重试 ✅
- Dead letter queue ✅

| ID | 严重性 | 描述 |
|----|--------|------|
| P2-29 | P2 | webhook endpoint 的 `Secret` 字段使用 `json:"secret,omitempty"` — API 响应中可能泄露 HMAC secret（应使用 `json:"-"` 或仅在创建时返回）|

### 3.10 依赖安全 — ⚠️ 差距

| ID | 严重性 | 描述 |
|----|--------|------|
| P2-30 | P2 | 无 `govulncheck` 或依赖漏洞扫描。go.mod 依赖版本较新但缺少 CI 中的自动化漏洞检查 |

### 3.11 JWT 密钥管理 — ✅ 安全

- RSA 2048 最小密钥大小 ✅
- 支持 AWS KMS / Vault / PKCS11 / 本地文件 ✅
- 密钥旋转 + grace period ✅
- alg whitelist 防止 alg confusion ✅
