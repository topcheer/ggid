## 3. 安全审查

### 3.1 JWT bearer grant — ParseUnverified

**文件**: `services/oauth/internal/service/oauth_service.go:2908`

```go
token, _, err := new(jwt.Parser).ParseUnverified(req.Assertion, jwt.MapClaims{})
```

RFC 7523 §3 要求 JWT bearer assertion 必须验证签名。当前使用 ParseUnverified 仅提取 claims。注释说 "In production, the assertion would be verified against a trusted issuer's JWKS" 但未实现。攻击者可伪造 JWT assertion 获取 access token。

| ID | 严重性 | 描述 |
|----|--------|------|
| P1-13 | P1 | JWT bearer grant 使用 ParseUnverified — 不验证 assertion 签名，攻击者可伪造 assertion 获取 token |
