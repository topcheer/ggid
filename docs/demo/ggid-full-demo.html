platform:admin
  • 创建/暂停/激活租户

  • 全局威胁仪表盘

  • OAuth/Webhook/API Key
  • Branding / Feature Flags
  • Impersonation / Secrets
  • 审计日志 (本租户)

🟢 Regular User

user:self
  • 个人 Dashboard
  • 我的会话
  • 访问申请
  • 个人资料管理

关键设计

JWT claims 按 tenant_id 过滤角色 — 用户在 Tenant A 有 tenant:admin 不代表在 Tenant B 也有。Platform:admin 不自动继承任何租户内部权限，除非同时被分配为该租户的 tenant:admin。

gateway/router.go checkRouteScope · oauth_service.go fetchUserRoleKeys(tenant_id)

三角色差异

Instance Admin

功能亮点

用户列表展示头像/邮箱/角色徽章/状态标签。支持实时搜索（q= 参数，后端 LIKE 查询）。每个用户可查看详情、分配角色、重置密码、删除。

RLS (Row Level Security) 确保用户只能看到当前 tenant 的用户数据。PasswordGrant 登录时通过 SET app.tenant_id 设置 RLS 上下文。

GET /api/v1/users · RLS: app.tenant_id · Scope: tenant:admin

用户详情 User Detail

Tenant Admin

功能亮点

用户详情页展示：基本信息、角色管理（分配/移除角色，带 UI 反馈）、凭据（密码/MFA/Passkey/SCIM/Social）、活跃会话、活动时间线。

角色徽章通过 role_name/role_id fallback 链显示，支持对象数组 [{role_id, role_name}] 格式。

GET /api/v1/users/{id} · roles/{id}/credentials · sessions · activity

角色管理 Roles & Permissions

Tenant Admin

功能亮点

支持创建自定义角色、分配细粒度权限（如 users:read, roles:write）、设置角色层级。权限矩阵可视化展示角色 × 权限关系。支持 ABAC (Attribute-Based Access Control) 策略构建器。

系统预置角色：Administrator (tenant:admin)、Editor、Viewer。角色按 tenant 隔离存储。

GET/POST/PUT/DELETE /api/v1/roles · permission_ids 数组格式 · RBAC enforcement

GET /api/v1/orgs/tree · departments 子路径路由修复

安全策略 Security

CAE · MFA · 密码策略 · ITDR · 安全态势

条件访问 Conditional Access (CAE)

Tenant Admin

功能亮点

可视化构建 IF-THEN 访问策略：IF device_posture < 70 THEN require_mfa。支持条件（设备姿态/风险评分/IP 范围/时间段/地理位置/MFA 状态）和动作（allow/deny/require_mfa/require_step_up/block）。

策略持久化到后端（POST/PUT/DELETE /policies/conditional-access），前端 conditions 数组 ↔ 后端 map 格式自动转换。策略在登录时执行拦截。

commit 5de4c4322 (持久化) · commit 58d222d57 (登录拦截)

多因素认证 MFA

所有用户可设置

功能亮点

三种 MFA 方式：TOTP（Google Authenticator/Authy，二维码扫描）、WebAuthn（Face ID/Touch ID/YubiKey 无密码认证）、备份方式（SMS/Email 验证码）。

Setup 返回 device_id + secret + otpauth URI，Verify 需要传入 device_id + 6 位 TOTP 码。成功后生成恢复码。

POST /api/v1/auth/mfa/setup → device_id · POST /mfa/verify → verified:true

ITDR 威胁检测 Identity Threat Detection

Tenant Admin

功能亮点

身份威胁检测与响应：MFA 疲劳攻击检测、不可能旅行（Impossible Travel）、凭证填充（Credential Stuffing）、令牌窃取（Token Theft）检测。自动响应（contain/resolve/investigating）。

MITRE ATT&CK 覆盖率 82% · 自动事件响应

安全态势 Security Posture

Tenant Admin

功能亮点

安全态势评分 75/100，包括 ITDR 覆盖率(88)、风险平均值(34)、DLP 合规(94)、MITRE 覆盖(82)。风险分布按用户分群：Low 83% / Medium 12% / High 3% / Critical 1%。

GET /api/v1/security/dashboard · failed_logins_24h=14

审计合规 Audit & Compliance

Hash Chain 防篡改 · 全局审计 · 威胁仪表盘

审计日志 Audit Log

Tenant Admin

功能亮点

审计事件通过 HMAC-SHA256 hash chain 形成链式结构，任何篡改都会导致链断裂被检测。支持按时间/操作者/动作/结果筛选。审计事件 IP 地址自动清洗（去除端口号，兼容 PostgreSQL inet 类型）。

domain.ComputeHash · repair-chain 工具 · inet IP:PORT 清洗

全局审计 Global Audit

仅 Instance Admin

功能亮点

实例管理员可查看所有租户的审计事件，进行跨租户安全分析。Tenant Admin 无法访问此页面（RBAC 限制 platform:admin scope）。

platformOnlyPaths: /api/v1/admin/audit/global · Scope: platform:admin

威胁仪表盘 Threat Dashboard

仅 Instance Admin

功能亮点

41 个活跃威胁(24h)：Critical 2 / High 5 / Medium 11 / Low 23。最近事件包括 MFA 疲劳攻击、不可能旅行、凭证填充、令牌窃取。

GET /api/v1/admin/threats/dashboard · Scope: platform:admin

Tenant Admin

功能亮点

API Key 管理

运维管理 Administration

用户模拟 Impersonation

Tenant Admin

功能亮点

管理员模拟用户完整流程：搜索用户 → 选择 → 输入合规理由（≥10字符）→ Start Impersonation → 后端签发 impersonation JWT（HS256, imp=true claim, 15min TTL）→ Banner 显示 "Impersonating X" → End Session 恢复。

所有模拟操作记录到审计日志（actor + target + reason）。

5-layer fix: 路径+参数+JWT+history+banner · commits 9c99c59da ~ 94fea7c09

Secrets 管理

Tenant Admin

功能亮点

租户级密钥管理：查看当前 JWT/OAuth/加密密钥状态，执行密钥轮换（graceful rotation，新旧密钥并行验证直到过期）。数据按 tenant 隔离。

/api/v1/admin/secrets · adminOnlyPaths (从 platformOnly 移入)

备份与灾难恢复 Backup & DR

Tenant Admin

功能亮点

租户数据备份管理：手动触发备份、查看备份历史、灾难恢复策略配置。数据按 tenant 隔离，备份只包含当前租户数据。

/api/v1/admin/backup · per-tenant isolation
