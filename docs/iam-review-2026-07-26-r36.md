## 3. 安全审查（新维度）

### 3.1 OIDC id_token 验证链

| 检查项 | 状态 | 说明 |
|--------|------|------|
| id_token 签发 | ✅ | issueIDToken (oauth_service.go:1128) — RS256 + nonce + iss/sub/aud |

| 检查项 | 状态 | 说明 |
