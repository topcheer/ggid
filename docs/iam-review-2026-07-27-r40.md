### 3.1 Backchannel logout token — ParseUnverified

**文件**: `services/oauth/internal/service/oauth_service.go:2795`


验证了 sub/sid、events claim、nonce 不存在、jti replay — 但**不验证签名**。攻击者可伪造 logout token 触发任意用户注销。
